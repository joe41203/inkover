## 名前（45 文字以内）

```
inkover — 共有中の画面に描き込むペン
```

## 概要（132 文字以内）

```
Web 会議で画面共有しながら、表示中のページに直接ペンで描き込めます。描いた線は数秒で自動的に消えるので、消す操作も要りません。完全ローカル動作・登録不要。
```

## 詳細な説明

```
inkover は、Web 会議で画面共有しているときに「ここです」を口で説明しなくて済むようにするための Chrome 拡張です。

拡張のアイコンを押すと、いま見ているページの上に直接描けるようになります。赤ペンで囲む、矢印で指す、番号を振る。描いた線は数秒で自動的に消えるので、消しゴムに持ち替える必要も、消し忘れて画面が汚れることもありません。


■ 相手にもちゃんと映ります

画面共有はブラウザが描いた結果をそのまま送るので、inkover が描いた線もページの一部として相手に届きます。タブ共有・ウィンドウ共有・画面全体共有のいずれでも映り、相手側に拡張を入れてもらう必要はありません。Google Meet、Zoom、Microsoft Teams など、会議ツールを問わず使えます。


■ 8 つのツール

・ペン（P） 手描きの線。ペンタブレットの筆圧にも対応
・矢印（A） 注目してほしい場所を指す
・直線（L） Shift で 45 度刻みに固定
・矩形（R） Shift で正方形
・楕円（E） Shift で正円
・スポットライト（O） 選んだ範囲以外を暗くして一点に集中させる
・テキスト（T） 文字を書き込む
・ステップ（S） 手順を示す連番バッジ

キー 1 つで切り替わるので、手元を見ずに持ち替えられます。


■ 主なショートカット

・Alt+Shift+D 描画モードの開始と終了
・1〜7 色の切り替え（7 色）
・Cmd/Ctrl+Z 直前の描画を取り消し
・Delete / Backspace 全消去
・F 消えるインクの ON / OFF
・H ページ操作モード（クリックがページに届くようになります）
・Esc 終了


■ プライバシー

inkover は実行時に外部への通信を一切行いません。描いた線はブラウザのメモリの中だけに存在し、閉じれば消えます。

要求する権限は 3 つだけです。

・activeTab アイコンを押した、そのタブだけ。押すまでは何も見ません
・scripting 押されたときに描画キャンバスを重ねるため
・storage 選んだ色と太さを次回に引き継ぐため

すべてのサイトへのアクセス権は要求しません。閲覧履歴も、開いているページの内容も取得しません。アカウント登録も不要です。

ソースコードはすべて公開しています。
https://github.com/joe41203/inkover


■ 動作しない場所について

ブラウザ拡張の仕組み上、以下では動作しません。

・ブラウザの外（PowerPoint やデスクトップアプリの上）には描けません
・chrome:// で始まるページ、Chrome ウェブストア、Chrome 内蔵の PDF ビューア

ブラウザ以外の画面にも描きたい場合は、デスクトップアプリ型のツールが必要になります。
```

## プライバシー慣行（Privacy practices）

### 単一用途の説明

```
Web 会議の画面共有中に、表示中のウェブページの上へ一時的な注釈を描画するための拡張機能です。
```

### 権限の justification

**activeTab**

```
ユーザーが拡張機能のアイコンをクリックした、そのタブにのみ描画用のキャンバスを重ねるために必要です。クリックされるまでいかなるタブにもアクセスしません。ページの内容の読み取りは行いません。
```

**scripting**

```
ユーザーがアイコンをクリックした時点で、描画用のキャンバスとツールバーを現在のタブへ注入するために使用します。静的な content_scripts 登録を行わず、この API による動的注入のみを用いることで、host_permissions を不要にしています。
```

**storage**

```
ユーザーが選択したペンの色・線の太さ・ツール・消えるインクの有効無効を chrome.storage.local に保存し、次回の起動時に引き継ぐために使用します。個人を識別できる情報は保存せず、外部にも送信しません。
```

### データ利用の申告

すべて「収集しない」を選択する。以下に該当しない:

- 個人を特定できる情報
- 健康情報
- 金融情報や支払い情報
- 認証情報
- 個人的な通信内容
- 位置情報
- ウェブ閲覧履歴
- ユーザーのアクティビティ
- ウェブサイトのコンテンツ

**補足**: 本拡張はページの内容を読み取らず、描画内容はメモリ上にのみ保持する。保存するのは色・太さ等の UI 設定のみで、リモートへの送信は一切ない。

### 3 つの表明にチェック

- 認められている用途以外でユーザーデータを販売または譲渡していません
- 承認された用途と無関係な目的でユーザーデータを使用または譲渡していません
- ユーザーデータの信用力の判断や融資目的での使用または譲渡をしていません
